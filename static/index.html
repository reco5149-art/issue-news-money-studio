PUBLISHING

꾸준히, 하루 10개의 이야기.

시간 기준: 한국 표준시 (KST) · 프로그램이 실행 중일 때 작업합니다.

매일 초안 자동 생성

연결한 뉴스에서 원문을 확인할 수 있는 소재만 최대 10개 제작합니다. 생성 후 검토하고 게시 시간을 예약하세요.

게시 운영 안내

  1. 콘텐츠 보관함에서 카드와 출처를 검토합니다.
  2. 사실관계·이미지 사용 권한 확인을 저장합니다.
  3. 게시 시간을 예약하면 자동으로 발행됩니다.

인스타그램 토큰, 게시 권한, 공개 HTTPS 이미지 주소가 필요합니다. 자동 생성된 초안을 검토 없이 게시하는 기능은 현재 버전에 포함되지 않습니다.

예약한 콘텐츠

실행 기록

CONNECTIONS

제작실의 도구를 연결하세요.

키는 프로젝트의 .env 파일에 저장하고, 프로그램을 재시작하세요.

인스타그램 연결 순서

  1. 프로페셔널 계정과 Meta 개발자 앱을 준비합니다.
  2. Instagram Login의 콘텐츠 게시 권한을 가진 토큰·사용자 ID를 .env에 입력합니다.
  3. 공개 미디어 서버에 data/media 폴더를 동기화하고 PUBLIC_MEDIA_BASE_URL을 지정합니다.
  4. 단일 카드 테스트 게시 후 캐러셀·예약 게시를 검증합니다.

이 로컬 앱에는 외부 공개용 로그인 기능이 없습니다. 앱 전체를 인터넷에 공개하지 마세요. 인스타그램에는 이미지 폴더만 제공해야 합니다.

.env.example 및 DevelopDoc/TECH_SPEC.md에 자세한 설정과 지원 범위가 있습니다. 연결 표시는 키의 존재 여부이며 인증 성공 확인은 아닙니다.

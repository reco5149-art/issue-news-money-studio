# 사진·문안 자가평가와 게시 조건

## 기준 v2

| 항목 | 배점 | 판단 내용 |
|---|---:|---|
| 후킹 | 25 | 구체성, 독자 관련성, 제목과 본문 약속 일치 |
| 사진·문안 일치 | 40 | 실제 보이는 행동·사물·상황이 문구를 뒷받침하는가 |
| 원고 근거 | 25 | 제공한 원고로 사실·숫자·주장을 뒷받침하는가 |
| CTA·전개 | 10 | 각 장의 역할, 자연스러운 행동 유도 |

모든 카드가 총점 80점 이상, 사진 일치 30점 이상, 근거 20점 이상이며 중대 오류가
없어야 통과한다. 평균 점수로 낮은 점수의 카드를 숨기지 않는다. 기준은 초기 편집
정책이며 실제 조회수·수익에 대해 보정된 모델이 아니다.

## 평가 흐름

완성된 실제 게시 JPEG와 입력 원고·제목·본문·캡션을 OpenAI Responses 이미지 입력으로
전달한다. 생성 후 자동 평가하고, 편집창에 점수·판단 근거·수정 제안을 보여준다.
사진 생성 방식과 별개로 평가 API 비용이 발생한다. 평가 모델은 OPENAI_REVIEW_MODEL,
미설정 시 OPENAI_TEXT_MODEL, 최종 기본값은 gpt-4.1-mini이다.

수정 후 저장하고 ‘저장된 내용 다시 평가’를 누른다. 문구·사진·캡션·출처나 실제 JPEG가
바뀌면 콘텐츠 지문이 달라지므로 기존 통과 결과를 사용할 수 없다. 체크박스만 저장하면
통과를 유지한다. 예약 API와 실제 게시 함수 양쪽에서 현재 지문과 점수·스키마를 검사한다.
기존 미평가 예약도 검사 대상이다. 기준 미달·미평가·오류·불완전 응답은 게시를 막는다.
평가에 실패해도 생성된 초안은 보관한다. 자동 수정이나 재생성을 무한 반복하지 않는다.

## 판단 한계

AI 평가 자체도 오판할 수 있다. 외부 사실 검증, 저작권 확인, 인물 신원 판별, 조회수
예측을 대신하지 않는다. 제목·해시태그뿐인 원문으로 영상의 경위·감정·여론을 확정할 수
없으며 구체적인 주장의 근거가 부족하면 보류하도록 지시한다. 자체 디자인은 사진 부재
자체로 감점하지 않는다. 사람이 사실과 권한을 확인하고 예약하는 기존 절차를 유지한다.

### v2 추가 기준

사건과 무관한 구독·채널 홍보·엔딩 화면은 중대 오류로 본다. 방송 로고·불필요한 방송
자막이 주제 집중을 방해하면 사진 일치도 29점 이하로 평가하도록 지시한다.
기존 v1 통과 기록은 새 기준의 게시 요건을 충족하지 않으므로 재평가해야 한다.

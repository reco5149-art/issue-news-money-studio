# 후킹형 카드뉴스 개선

## 문제와 변경

기존 AI 지침은 첫 장 후크, 중간 핵심, 마지막 CTA라는 일반적인 구조에 그쳤다.
전달 방식에 **후킹형**을 추가하고 기본 선택으로 설정했다. AI 요약을 선택하면
독자에게 중요한 변화나 구체적인 효용을 표지에서 전달하고, 다음 장에서 바로 설명한다.
중간 장 제목은 범용 번호 대신 실제 내용을 전달한다. 마지막 장과 캡션에는 입력한 CTA를
주제에 맞춰 연결한다. 정보형·공감형·질문형도 계속 선택할 수 있다.

로컬 원문 배치는 AI 문안 작성이 아니다. 기존처럼 원문을 배치하며 화면에서 차이를 안내한다.
기존 저장 콘텐츠는 자동으로 다시 쓰지 않는다. 새 생성부터 적용한다.

화면 기본 생성 방식은 AI 자동 기획·후킹이다. API의 engine 기본값은 기존 호출과의
호환성을 위해 local로 유지한다. AI는 입력 유형과 근거를 판단한 뒤 실용성·비교·변화·공감
중 맞는 관점을 선택한다. 선택된 카테고리보다 실제 원고를 우선한다.
주제만 입력하면 일반 설명 초안을 만들며 최신 사실을 검색해 검증한 것으로 주장하지 않는다.
기사·블로그 링크는 본문 가져오기 후 생성한다. 차단된 원문은 붙여넣기가 필요하다.
YouTube는 제목·설명만, Instagram·TikTok은 수동 원고가 필요하다는 기존 범위는 유지한다.

## 콘텐츠 운영 추천

아래 비율과 문구는 성과가 검증된 공식이 아닌 초기 실험안이다.
10개를 채우기보다 충분한 근거와 독자 효용이 있는 원고만 발행한다.

| 소재 | 10개 제작 시 실험 배분 | 독자에게 줄 가치 |
|---|---:|---|
| AI 활용 | 4 | 실제 사용 예시, 작업 순서, 도구의 한계 |
| 생활 경제 | 3 | 적용 대상, 확인할 조건, 비교 기준 |
| 뉴스·이슈 | 2 | 어떤 변화인지, 내 생활에 어떤 관련이 있는지 |
| 연예·문화 | 1 | 확인된 발언·작품의 맥락, 독자가 공감할 지점 |

예시(제목 형식 참고이며 실제 최신 뉴스 주장이 아님):
‘AI 답변, 출처부터 확인해야 하는 이유’, ‘지원금 신청 전 확인할 조건’,
‘새 요금제, 누구에게 유리할까?’. 숫자·기한·효용은 원문에서 확인될 때만 사용한다.
표지에서 핵심을 전달하고 다음 장에서 곧바로 근거를 제시한다. 마지막에는 본문 내용에
연결된 저장·공유·질문을 제안한다. 없는 무료 자료나 자동 DM을 약속하지 않는다.

월 1천만 원은 목표이며 조회수만으로 수익을 추산하지 않는다. 광고·협업, 실제 제작한
자료·서비스 등 계정 독자와 맞는 수익원을 별도로 검증한다. 매출과 비용 차감 후 수익은
구분한다. 현재 앱에는 매출·전환 추적이나 인스타 성과 자동 수집 기능이 없다.
같은 관찰 기간으로 도달, 저장/도달, 공유/도달, 프로필 방문과 실제 문의·구매를 기록한다.

Meta는 원본 콘텐츠를 우선하는 방향과 전문 대시보드의 콘텐츠·참여·도달·수익화 안내를
공개했다. 이를 바탕으로 단순 기사 재게시보다 자체 설명을 더하는 편집을 권장한다.
이는 추천 노출이나 저작물 사용 권한을 보장하지 않는다.

## 시연과 평가

전달 방식 **후킹형**, 생성 방식 **AI 요약**, 자체 디자인, 3장을 선택하고 같은 원고로
정보형 결과와 비교한다. 생성 결과의 사실·길이·조건을 검토한 뒤 문안을 편집한다.
프롬프트 지침은 생성 결과의 정확성을 보장하는 검증기가 아니므로 게시 전 검토가 필요하다.
조회수와 수익 증가는 아직 검증하지 않았다. 향후 유사 주제의 도달 수, 저장률, 공유율을
비교하되 게시 시각과 소재의 차이도 함께 기록한다.

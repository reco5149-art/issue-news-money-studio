## API

- `PUT /api/posting-cadence`: enabled, autopilot, daily_limit(1~20), start_hour, batch_size(2~3), batch_interval(60~90분), item_interval(5~20분).
- `POST /api/schedule/batch`: post_ids, 선택적 start_at. 기본은 다음 빈 시간대에 분산. consecutive=true이면 2~3개를 명시한 start_at에 연속 예약한다.
- `GET /api/status`: cadence 설정과 daily 초안 생성 설정을 구분해 제공.

# 서버 실행과 공개 체험

## 2026-10-01 확인

- Windows 마지막 부팅: 한국 시간 16:22:07. 기존 앱은 수동 시작 방식이어서 재부팅 후 자동 복구되지 않았다.
- 이전 모든 종료의 원인은 확정하지 못했다. 기존 로그에 종료 원인과 프로세스 종료 코드가 없다.
- GitHub 저장소 공개는 로컬 서버를 공개하지 않는다. 127.0.0.1은 접속한 사람 자신의 PC 주소다.

## 로컬 자동 복구

`scripts/install-server-watchdog.ps1`을 실행하면 현재 사용자의 로그인 시 `IssueStudio-ServerWatchdog` 작업이 시작된다. 30초마다 상태를 확인하고 8765 리스너가 없을 때 시작한다. 느린 요청을 장애로 오인하여 실행 중인 프로세스를 종료하지 않는다.

`stop.bat`은 data/server.paused를 만들어 자동 복구를 일시 정지한다. `start.bat`은 일시 정지를 해제한다. 진단 기록은 data/watchdog.log에 저장한다. PC 전원 종료·절전·로그아웃 중에는 서비스할 수 없으며 로그인 전 자동 시작을 보장하지 않는다.

## 외부 체험

public-demo는 GitHub Pages에 배포하는 독립 HTML/CSS/JavaScript 체험판이다. PC 서버 없이 원고의 문장 배치, 카드 수정, 비율 변경, PNG·캡션 다운로드가 가능하다. 입력값은 서버에 전송하거나 보관하지 않는다.

실제 AI 생성·뉴스 검색·이미지 생성·예약·인스타그램 게시·기존 콘텐츠 보관함은 포함하지 않는다. 운영 앱 API나 키를 공개하지 않는다. 정적 체험판을 전체 프로그램의 클라우드 배포로 표현하지 않는다.

전체 기능의 외부 서비스에는 별도 상시 서버, 사용자 인증, 사용자별 DB·파일 격리, 요청 제한과 비용 관리가 필요하다.

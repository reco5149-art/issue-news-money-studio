# 카드별 이미지

## 현재 카드 디자인 (2026-10-05)

새 생성은 `design_version=3`을 사용한다. 검정 계열 배경(#080B0A)에 상단 표제는
굵은 연두색(#C8FF16), 하단 첫 줄은 노란색(#FFE45E), 나머지 본문은 흰색이다.
표제 최대 88px, 본문 최대 46px이며 긴 문장은 어절 단위로 줄바꿈한다.
원본 사진 전체를 포함해 자막·로고·얼굴을 임의로 자르지 않는다.
AI 이미지는 설명용 표시를 유지한다. 렌더러는 `app/bold_render.py`이다.

기존 버전은 기존 렌더러로 유지된다. 게시 완료 이미지의 디자인을 고칠 때는
새 초안을 만들어 재평가하며, 기존 Instagram 게시 기록과 원본 파일을 덮어쓰지 않는다.
아래 사진 영역 설명 중 과거 비율·그라데이션은 이전 디자인에 해당한다.

## 동작

기존에는 원고 전체로 이미지 한 장을 만들고 모든 카드에 반복 사용했다.
이제 AI 이미지 모드는 문안을 먼저 만든 후 각 카드의 제목과 본문을 사용해
각각의 설명용 이미지를 생성한다. 카드 5장은 이미지 API 호출 5회이므로 비용과
대기 시간이 장수에 비례해 늘어난다. 실제 보도사진으로 표현하지 않는다.

문안 편집창의 **이 카드 사진 교체**에서 사진을 업로드하고 저장하면 해당 장에만
적용한다. 보유 사진·웹 검색·영상 캡처의 초기 선택은 공통 사진으로 유지한다.
기존 콘텐츠는 문안 편집으로 장별 교체 가능하며 자동 재생성하지 않는다.
문구만 수정할 때 사진을 다시 생성하지 않는다. 내용에 맞는지 사용자가 확인한다.
사진 교체 후 이용 권한 확인 상태를 해제한다.

## 저장과 호환성

각 슬라이드에 asset_id와 image_credit를 저장한다. 예전 콘텐츠와 요청은 공통
asset_id를 사용할 수 있다. 문안 편집에서 사진 ID를 생략하면 기존 장별 사진을
유지한다. 이미지 출처를 캡션에 포함하고 AI 생성 표시를 해당 카드에 표시한다.
생성 중 실패하면 완성된 게시물은 저장하지 않으며 재시도 시 생성 비용이 다시
발생할 수 있다. 앞서 만든 임시 자산 파일은 남을 수 있다.

## KIE AI 이미지 엔진 (2026-10-01)

AI 이미지 모드에서 엔진을 **KIE AI**(화면 기본 선택) 또는 **OpenAI**로 고른다. API 기본값은
기존 호환을 위해 OpenAI이다. KIE AI는 비동기 작업이라 작업 생성 → 상태 조회 → 결과 다운로드
순서로 처리하고, 카드 3장까지 동시에 요청한다. 한 장이 실패하면 대기 중인 요청은 취소하지만 이미
생성 요청한 작업은 과금될 수 있다. 결과 이미지는 공개 주소 검사를 거쳐 20MB 이하만 받는다.

카드 렌더링은 사진을 카드 위쪽 54% 영역에 채우므로, 카드 전체 비율이 아니라 사진 영역 비율로
생성한다: 4:5 카드 → 3:2, 1:1 카드 → 16:9, 9:16 카드 → 1:1. 프롬프트에 핵심 피사체를 위·가운데에
두라고 지시한다(아래쪽은 그라데이션과 문구, 위 모서리는 라벨). 이미지 출처는 카드와 캡션에
`AI 생성 이미지 (KIE AI · 모델명)`으로 기록한다. KIE 키가 없으면 문안 생성 전에 중단한다.

- [x] 작업 생성·상태 조회·다운로드, 사진 영역 비율 전달 (모의 API)
- [x] 크레딧 부족·생성 실패·시간 초과·이미지 아닌 결과·키 누락 처리, 시간 초과 시 재요청 없음
- [x] KIE 선택 시 OpenAI 이미지 미호출, 카드별 다른 이미지와 출처 표시
- [ ] 실제 KIE AI 계정으로 이미지 생성 및 결과 내용 검토 (유료 호출이라 사용자 승인 후 진행)


## 짧은 문안과 영상 확대 (2026-10-07)

새 AI 생성에는 compact-v1을 적용한다. 제목은 12~24자를 권장하고 최대 32자,
본문은 한 가지 사실을 한 문장으로 써 최대 70자, 캡션 생성문은 최대 420자로 제한한다.
길이를 넘으면 원문에서 한 번 다시 요약하며, 중요한 조건이나 반론을 기계적으로 잘라내지 않는다.
CTA 문장은 캡션에 한 번만 쓰며, 카드에는 짧은 이동·저장 버튼을 사용한다.
로컬 배치 모드는 AI 요약이 아니며 별도 편집이 필요하다.

영상은 yt-dlp 캡처 후 약 1.1배 크롭, 측면·하단 크롭, 장면별 크롭을 순서대로 검수한다.
AI가 확대본의 로고를 검사할 때 원본을 함께 주면 혼동하는 사례가 있어,
방송 그래픽 검출은 확대본만 검사하고 인물·핵심 동작 보존은 원본과 별도 비교한다.
로고가 남거나 주요 얼굴이 잘리면 사용하지 않는다. 실제 현장의 표지판·옷·명패는
방송 오버레이와 구별한다. 장면에 따라 적절한 크롭이 불가능할 수 있다.

공개 캡션에서는 URL을 제거한다. 원문 주소와 이미지 출처·권한 정보는 게시물 데이터와
자산 메타데이터에 보관한다. AI 생성 표시·필요한 이미지 표시와 출처 이름은 유지한다.
영상 자산에는 cleanup=overlay-crop-v2를 기록한다. 이 메타데이터는 이용허락을 의미하지 않는다.
이 변경은 새 생성과 편집 저장에 적용하며 이미 게시된 콘텐츠를 일괄 수정하지 않는다.
